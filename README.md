# To-Do List

A simple browser-based to-do list built with HTML, CSS, and vanilla JavaScript. Add tasks, filter the list as you type, and remove tasks when they are done.

## Features

- Add tasks using the form or the **Add** button
- Search tasks with case-insensitive, Turkish-locale-aware filtering
- Delete tasks from the list
- Responsive layout styled with Bootstrap
- No installation or build step required

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter a task and click **Add** (or press Enter).
4. Use the search field to filter tasks, or click the trash icon to remove one.
